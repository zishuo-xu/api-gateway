用户接入：只要两样东西

把下面的地址和 Key 发给用户即可，用户看不到也拿不到你的下游密钥
1网关地址（Base URL）
-
所有用户共用，就是本控制台所在的地址
2API Key
gw-在「API Keys」页签签发
每用户一把，放在 X-API-Key 请求头里
两把钥匙别搞混
  • 下游 Key：你在「路由配置」里填的提供商密钥，网关代持，只存在服务端，永远不下发给用户。
  • 用户 Key：在「API Keys」页签签发、以 gw- 开头的那串，给用户本人用，可随时停用。
用户请求时，网关校验用户 Key → 匹配前缀 → 自动注入下游 Key → 转发 → 原样返回。

两种接入方式

推荐第一种：换模型即换供应商，客户端地址永远不变
推荐统一入口 · 按模型自动路由
-
任何 OpenAI 兼容客户端都直接填这个 Base URL，不要再拼 /v1。 网关读请求体里的 model 决定转发给哪个供应商； 换供应商只需改 model 名字，地址不动。
GET /v1/models 可列出全部可用模型。
备用供应商专属前缀 · 强制指定渠道
-
同一个模型在多个供应商都有时，用它锁定某一家； 或者你的客户端压根不支持自定义 Base URL。
注意：这里不要再自己加 /v1，前缀已经指向具体的上游了。

各模型的完整调用地址

网关地址 + 匹配前缀 + 接口路径，按你当前的路由实时生成
名称完整 URI可调用模型复制
还没有配置任何下游路由。先去「路由配置」页签添加一条，这里会自动生成对应的调用地址。
